# Проверка версии 0.1

Дата: 2026-11-08. Эталон — выбранный пользователем «Полевой справочник»: `docs/design/field-manual-approved.png`.

## Визуальное соответствие

Сверены шапка, навигация глав, локальное оглавление, типографика, таблицы, примечания, мобильная панель и контекст главы у прямой ссылки. Сводное сравнение: [.impeccable/review/comparison.jpg](.impeccable/review/comparison.jpg). Скриншоты реального сайта, включая полную главу, находятся в `.impeccable/review/`.

Браузерные размеры: 1440×1000 и 390×844 CSS px. Захват браузера может исключать полосу прокрутки и масштабировать растр; размеры PNG отличаются от CSS viewport. Горизонтального переполнения страницы на этих размерах не обнаружено. Оригинальные широкие таблицы прокручиваются внутри собственной области.

Полные формулировки, списки и иллюстрации исходника делают страницу длиннее сокращённого фрагмента макета. Содержание не удалялось для воспроизведения его высоты. Страницы разделены по десяти главам, пункты доступны через оглавления и прямые ссылки.

## Независимая проверка

Первый ручной review: `fix`, три замечания. Исправлены мобильный возврат к главе, совпадение условий нечёткого поиска и подсветки, светлый фокус на тёмных поверхностях.

Вердикт повторной проверки: **ship** — все три замечания **resolved**, регрессий в рамках этой проверки не обнаружено. Это вердикт по указанным исправлениям, а не сертификация всех экранов и браузеров. Отчёты: `finish-review.md`, `finish-verdict.md` в `.impeccable/review/`.

Impeccable engine в окружении недоступен; автоматические detect/comp-diff не выполнялись. Сравнение проведено по утверждённому изображению и реальным снимкам.

## Функциональная проверка

- 11 тестов Node: словоформы, е/ё, точный заголовок, опечатки, сокращения, данные из иллюстраций, отсутствие результатов, подсветка длинных слов с двумя опечатками.
- Тесты service worker: полная офлайн-копия, поиск с query string, PDF из кэша, отказ неполной/изменившейся загрузки, переключение только после принятия, очистка только собственных старых кэшей.
- `scripts/verify.py`: 15 HTML-страниц, 54 раздела поиска, 94 ресурса с SHA-256; внутренние ссылки/якоря, изображения с alt, PDF-закладки; 607 текстовых фрагментов совпадают в HTML, PDF и поисковом индексе.
- В браузере: меню глав с закрытием, поиск и подсветка по прямой ссылке, предложение/принятие обновления, видимый фокус, отсутствие ошибок в консоли проверенных страниц.
- Локальный HTTP-сервер остановлен: переход на поиск, поиск «транпортиовка», переход к результату и перезагрузка главы работают из service worker. После отдельного исправления проверено мгновенное появление сохранённой версии при перезагрузке без сервера. Сервер после проверки запущен снова.
- PDF по ссылке кнопки скачан; SHA-256 совпал с файлом сборки. Нативное событие загрузки при выключенном сервере автоматизация не подтвердила (timeout); наличие PDF в офлайн-кэше проверено отдельным тестом.

Кликабельное оглавление и PDF-закладки присутствуют. Изображения не обрезаны, таблицы и редакционные примечания читаемы.

## Внешняя публикация

Версия 0.1 опубликована 2026-11-08: [сайт](https://vasilevkostya.github.io/bronepehota/), [публичный репозиторий](https://github.com/VasilevKostya/bronepehota).

[GitHub Actions №42504974612](https://github.com/VasilevKostya/bronepehota/actions/runs/42504974612) завершился успешно: сборка, 11 тестов Node, сверка 15 HTML-страниц / 54 поисковых разделов / 53 страниц PDF / 607 текстовых фрагментов и развёртывание Pages.

Проверка `scripts/verify_deployed.py` выполнилась на сервере GitHub по публичному HTTPS-адресу: главная страница, service worker и все 94 файла офлайн-редакции доступны; SHA-256 каждого файла совпадает с манифестом сборки `ede8a331ce9dae05`. Проверка теперь запускается после каждой публикации и отклоняет старую или неполную редакцию.

Первый прогон выявил служебный скрытый файл `.nojekyll` в офлайн-манифесте: на Pages он не отдавался, и атомарная установка кэша не могла завершиться. Скрытые служебные файлы исключены из манифеста; в `scripts/verify.py` добавлена проверка от повторного включения. Игровые материалы и визуальная система не менялись.

Ограничение: открытие публичного сайта в браузере текущего окружения завершилось `ERR_CONNECTION_TIMED_OUT`; отдельный HTTP-запрос из этой сети также получил тайм-аут. Поэтому интерактивная браузерная проверка именно публичного домена не заявляется. Ранее выполненные проверки поиска, навигации и офлайн-сценариев относятся к локальному сайту; доступность и целостность опубликованных файлов подтверждены отдельным прогоном в GitHub Actions.
