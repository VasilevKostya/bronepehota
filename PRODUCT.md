# Бронепехота

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Статический сайт без клиентского фреймворка: Python собирает HTML, поисковый индекс и PDF из JSON; браузер использует обычные CSS и JavaScript ES-модули. PDF формируется ReportLab, иллюстрации обрабатываются Pillow. Локальные шрифты и SVG входят в сборку; Service Worker сохраняет полную редакцию. Целевая публикация — GitHub Pages.

## Users

Основной пользователь — игрок, который во время партии ищет правило или характеристики подразделения с телефона. Второй сценарий — последовательное изучение правил и просмотр каталога на телефоне или компьютере.

## Product Purpose

Русскоязычный справочник правил и каталог подразделений «Бронепехоты». Текущая редакция правил — «Уральская версия 0.3» от 2026-11-11. Первая опубликованная редакция — 0.1. Каталог расширяет сайт без изменения редакции правил и PDF.

## Capabilities and Constraints

- Правила по главам и отдельный каталог подразделений. Утверждённое 2026-11-12 расширение заменяет прежнюю заглушку: пункт навигации называется «Каталог», старый адрес `armies.html` перенаправляет в него. Отдельного раздела «Армлисты», конструктора армии, скачивания карточек и PDF каталога нет.
- Поиск по тексту и таблицам с учётом русских словоформ, е/ё, сокращений и небольших опечаток. Результаты содержат фрагмент, подсветку и ссылку на пункт.
- Работа правил и поиска без интернета после полной первоначальной загрузки; видимая сохранённая версия и предложение обновления.
- Скачиваемый PDF A4 для экрана и печати: оглавление, нумерация страниц, таблицы и иллюстрации. Сайт и PDF собираются из одного источника и имеют одинаковую редакцию.
- Формулировки и механику исходника сохраняем. Очевидные опечатки исправляем с фиксацией; содержательные правки требуют решения пользователя. Противоречия отмечаем «Требует уточнения» одинаково на сайте и в PDF.
- Контент хранится в понятных файлах. Будущая автоматическая сборка обновляет сайт, поисковый индекс и PDF.
- Публичный репозиторий — `VasilevKostya/bronepehota`; адрес GitHub Pages — `https://vasilevkostya.github.io/bronepehota/`. Версия 0.1 опубликована 2026-11-08.

## Каталог подразделений — утверждено 2026-11-12

- 105 самостоятельных записей из предоставленных листов: 70 пехотных отрядов с 414 индивидуальными профилями, 31 единица техники, 2 кавалерийские единицы и 2 героя; 6 фракций. Разные варианты одного названия остаются отдельными карточками и связаны блоком «Другие варианты».
- Список с поиском по названию, вооружению и свойствам; фильтры по фракции, типу, диапазону стоимости, армейскому рангу и тестовому статусу. Поиск учитывает е/ё, русские словоформы, обозначения кубиков и заданные синонимы/транслитерации. Тестовый статус виден текстом «Тест».
- Каждая карточка имеет постоянный адрес и действие «Ссылка». Возврат к каталогу сохраняет запрос и фильтры в URL, а положение списка — в текущем сеансе браузера. При недоступности хранилища сеанса сохранение положения не гарантируется.
- Пехота: крупные полные изображения бойцов горизонтально, индивидуальные характеристики вертикально под каждым. На телефоне таблица прокручивается локально; названия строк закреплены слева. Техника, кавалерия и герои сохраняют собственные характеристики, вооружение, шкалы и способности исходных листов.
- Обозначения и свойства связаны с раскрываемым словарём и соответствующими правилами. Нерешённые вопросы явно отделяются примечанием «Требует уточнения»; перенос не усредняет профили и не вводит новые игровые механики.
- 554 принятых прозрачных вырезки представлены в двух размерах. Все малые изображения, страницы и поисковый индекс входят в обязательную офлайн-сборку. Увеличенные ×4 загружаются и сохраняются по мере просмотра на компьютере с проверкой SHA-256; при недоступности используется малая версия. Интерполяция ×4 не добавляет исходной детализации.
- Полный список и карточки доступны без JavaScript; поиск, фильтры и установка офлайн-копии требуют JavaScript. Ошибка загрузки поиска оставляет карточки доступными и предлагает повтор; пустой результат предлагает сбросить запрос и фильтры.

## Форум — утверждено 2026-11-09

- GitHub Discussions в существующем публичном репозитории: бесплатно, без собственного сервера и базы данных. Справочник остаётся на GitHub Pages.
- Постоянная ссылка «Форум» на компьютере и телефоне. Чтение публичное, участие через аккаунт GitHub; обсуждения требуют интернета.
- Основные категории: «Q&A» (вопросы по правилам), «Предложения по изменениям» (открытое обсуждение), «Объявления и новые редакции» (темы создаёт владелец/maintainer). При настройке владелец также сохранил General и «Голосования».
- Форма вопроса требует версию правил, ссылку на пункт и описание игровой ситуации. Первый модератор — владелец проекта. Имя категории Q&A согласовано пользователем после проверки 2026-11-09: при кириллическом имени GitHub не подключал форму; русские описание и поля сохранены.
- Обсуждение и отмеченный ответ сами по себе не меняют правила. Владелец утверждает изменения для следующей редакции сайта и PDF.
- Встраивание комментариев под пунктами и giscus отложены. Офлайн-режим справочника сохраняется.

## Product Principles

- Быстро находить правило и сохранять возможность читать главы последовательно.
- Узнавать фигурку и читать её собственный профиль; сохранять различия вариантов исходных листов.
- Разделять текст исходника и редакционные примечания.
- Поддерживать согласованность сайта, PDF и сохранённой офлайн-редакции.
- Документировать все принятые визуальные решения и актуализировать брендбук при изменениях.

## Accessibility & Inclusion

Читаемый русский текст, адаптивность, клавиатурная навигация и видимый фокус. Значение состояния передаётся не только цветом. Анимация учитывает настройку уменьшения движения.

## Уточнение обновлений — 2026-11-13

Повторное обновление загружает только изменённые файлы. Установка остаётся атомарной; неизменившиеся файлы и просмотренные увеличения используются между сборками. Прерванную загрузку можно продолжить без повторного скачивания проверенной части. Пользователь видит прогресс и может применить уже готовое обновление без сети.
