# Бронепехота

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Статический сайт без клиентского фреймворка: Python собирает HTML, поисковый индекс и PDF из JSON; браузер использует обычные CSS и JavaScript ES-модули. PDF формируется ReportLab, иллюстрации обрабатываются Pillow. Локальные шрифты и SVG входят в сборку; Service Worker сохраняет полную редакцию. Целевая публикация — GitHub Pages.

## Users

Основной пользователь — игрок, который во время партии ищет правило с телефона. Второй сценарий — последовательное изучение правил новичком на телефоне или компьютере.

## Product Purpose

Русскоязычный справочник правил «Бронепехоты». Текущая редакция — «Уральская версия 0.3» от 2026-11-11. Первая опубликованная редакция — 0.1.

## Capabilities and Constraints

- Первая версия: правила по главам; для армлистов — страница «Раздел готовится». Наполнение армлистов и конструктор ростеров отложены.
- Поиск по тексту и таблицам с учётом русских словоформ, е/ё, сокращений и небольших опечаток. Результаты содержат фрагмент, подсветку и ссылку на пункт.
- Работа правил и поиска без интернета после полной первоначальной загрузки; видимая сохранённая версия и предложение обновления.
- Скачиваемый PDF A4 для экрана и печати: оглавление, нумерация страниц, таблицы и иллюстрации. Сайт и PDF собираются из одного источника и имеют одинаковую редакцию.
- Формулировки и механику исходника сохраняем. Очевидные опечатки исправляем с фиксацией; содержательные правки требуют решения пользователя. Противоречия отмечаем «Требует уточнения» одинаково на сайте и в PDF.
- Контент хранится в понятных файлах. Будущая автоматическая сборка обновляет сайт, поисковый индекс и PDF.
- Публичный репозиторий — `VasilevKostya/bronepehota`; адрес GitHub Pages — `https://vasilevkostya.github.io/bronepehota/`. Версия 0.1 опубликована 2026-11-08.

## Форум — утверждено 2026-11-09

- GitHub Discussions в существующем публичном репозитории: бесплатно, без собственного сервера и базы данных. Справочник остаётся на GitHub Pages.
- Постоянная ссылка «Форум» на компьютере и телефоне. Чтение публичное, участие через аккаунт GitHub; обсуждения требуют интернета.
- Основные категории: «Q&A» (вопросы по правилам), «Предложения по изменениям» (открытое обсуждение), «Объявления и новые редакции» (темы создаёт владелец/maintainer). При настройке владелец также сохранил General и «Голосования».
- Форма вопроса требует версию правил, ссылку на пункт и описание игровой ситуации. Первый модератор — владелец проекта. Имя категории Q&A согласовано пользователем после проверки 2026-11-09: при кириллическом имени GitHub не подключал форму; русские описание и поля сохранены.
- Обсуждение и отмеченный ответ сами по себе не меняют правила. Владелец утверждает изменения для следующей редакции сайта и PDF.
- Встраивание комментариев под пунктами и giscus отложены. Офлайн-режим справочника сохраняется.

## Product Principles

- Быстро находить правило и сохранять возможность читать главы последовательно.
- Разделять текст исходника и редакционные примечания.
- Поддерживать согласованность сайта, PDF и сохранённой офлайн-редакции.
- Документировать все принятые визуальные решения и актуализировать брендбук при изменениях.

## Accessibility & Inclusion

Читаемый русский текст, адаптивность, клавиатурная навигация и видимый фокус. Значение состояния передаётся не только цветом. Анимация учитывает настройку уменьшения движения.

## Current Status

Редакция 0.3 от 2026-11-11 включает союзы и баланс армий, тестовое прицеливание, бесплатный поворот техники и укрытия пехотинцев по шести частям тела. Собраны 10 глав, 59 поисковых разделов, 53 исходные иллюстрации и PDF на 55 страницах A4. Все 11 тестов прошли; проверены 626 общих текстовых фрагментов в HTML, PDF и поиске, внутренние ссылки, закладки PDF и контрольные суммы 95 офлайн-ресурсов. Поиск проверен на новых терминах.

Визуально просмотрены все страницы PDF, крупно оглавление и изменённые страницы 5, 20, 30–32; после уточнения перехода к разделу машин повторно проверена изменившаяся страница 30. Браузерная проверка новой локальной сборки ограничена тайм-аутом подключения: встроенный браузер показывает сохранённую 0.2. Это не подтверждение отображения 0.3 на телефоне или компьютере.
