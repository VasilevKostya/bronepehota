# Бронепехота

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Статический сайт без клиентского фреймворка: Python собирает HTML, поисковый индекс и PDF из JSON; браузер использует обычные CSS и JavaScript ES-модули. PDF формируется ReportLab, иллюстрации обрабатываются Pillow. Локальные шрифты и SVG входят в сборку; Service Worker сохраняет полную редакцию. Целевая публикация — GitHub Pages.

## Users

Основной пользователь — игрок, который во время партии ищет правило с телефона. Второй сценарий — последовательное изучение правил новичком на телефоне или компьютере.

## Product Purpose

Русскоязычный справочник правил «Бронепехоты». Первая редакция — «Уральская версия 0.1». Дата выпуска определяется фактической публикацией.

## Capabilities and Constraints

- Первая версия: правила по главам; для армлистов — страница «Раздел готовится». Наполнение армлистов и конструктор ростеров отложены.
- Поиск по тексту и таблицам с учётом русских словоформ, е/ё, сокращений и небольших опечаток. Результаты содержат фрагмент, подсветку и ссылку на пункт.
- Работа правил и поиска без интернета после полной первоначальной загрузки; видимая сохранённая версия и предложение обновления.
- Скачиваемый PDF A4 для экрана и печати: оглавление, нумерация страниц, таблицы и иллюстрации. Сайт и PDF собираются из одного источника и имеют одинаковую редакцию.
- Формулировки и механику исходника сохраняем. Очевидные опечатки исправляем с фиксацией; содержательные правки требуют решения пользователя. Противоречия отмечаем «Требует уточнения» одинаково на сайте и в PDF.
- Контент хранится в понятных файлах. Будущая автоматическая сборка обновляет сайт, поисковый индекс и PDF.
- Согласован будущий публичный репозиторий `VasilevKostya/bronepehota` и адрес `https://vasilevkostya.github.io/bronepehota/`. Репозиторий и публикация ещё не созданы.

## Product Principles

- Быстро находить правило и сохранять возможность читать главы последовательно.
- Разделять текст исходника и редакционные примечания.
- Поддерживать согласованность сайта, PDF и сохранённой офлайн-редакции.
- Документировать все принятые визуальные решения и актуализировать брендбук при изменениях.

## Accessibility & Inclusion

Читаемый русский текст, адаптивность, клавиатурная навигация и видимый фокус. Значение состояния передаётся не только цветом. Анимация учитывает настройку уменьшения движения.
